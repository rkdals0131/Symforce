# Module Status

**Current Status:** The project is undergoing a refactoring to fully integrate SymForce with the GTSAM backend. The goal is to improve performance and accuracy by using SymForce to generate optimized custom factors for the SLAM problem.

**Next Steps:** The focus is on the `slam_core` module, where the code generation and integration will take place. Other modules will be updated as needed to support this new backend.
